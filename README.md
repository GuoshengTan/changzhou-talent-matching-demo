# 常州未来产业科研人才匹配演示

基于公开资料的科研能力检索演示，配套课题《基于推荐算法与多维画像的常州未来产业高层次人才精准匹配机制研究》。

## 使用

打开在线页面，或下载后双击 `index.html` / `打开演示.html`。页面支持选择技术方向、调整权重、查看资料依据及导出结果，无需登录。

## 数据与方法

- 10名科研人员的官方公开资料。
- 2份常州需求材料，提取3个技术方向，形成30组配对。
- 默认分数：0.7 × 显式标签覆盖率 + 0.3 × 字符二元组TF-IDF余弦相似度。
- 输入、来源与标签依据见 `public_data.json`，计算结果见 `results.json` 和CSV文件。

这是科研相关性检索演示，不是求职者库。招聘资格未核验，合作意愿未知；目的性小样本没有独立适配标签或实际对接结果，分数不代表人员综合水平、录用概率或招聘成效。

## 复算

安装Python 3，在本目录运行：

```sh
python match_public.py
```

核心计算仅依赖Python标准库。运行后更新 `results.json` 和 `全部匹配结果.csv`。页面内嵌数据，修改JSON后需要重新运行生成脚本才能同步网页。

可选：重新生成Word报告和演示页面：

```sh
python -m pip install -r requirements.txt
python build_deliverables.py
```

生成后将 `打开演示.html` 复制为 `index.html`，保持在线首页同步。`build_data.py` 保留数据整理过程，运行前请注意其会重新写入输入数据。

## 文件

| 文件 | 用途 |
| --- | --- |
| index.html、打开演示.html | 在线及离线交互演示 |
| public_data.json | 来源、人才记录及需求方向 |
| match_public.py | 匹配计算与权重检查 |
| results.json、全部匹配结果.csv | 配对结果 |
| 人才公开数据.csv、需求公开数据.csv | 便于查看的数据表 |
| 真实公开数据与匹配演示报告.docx | Word说明报告 |
| build_data.py、build_deliverables.py | 数据及成果生成脚本 |

资料来源链接保留在数据文件及报告中；来源资料的权利归原权利人所有。
